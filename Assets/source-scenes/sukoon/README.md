# Sukoon scene asset provenance

The source pond plates and fish sprite sheet in this folder were generated for this project with OpenAI's built-in image generation tool on 21 August 2026.

- `sukoon-source.png`: fish-free production backdrop used by the interactive scene.
- `sukoon-thumbnail-source.png`: alternate composition with six fish, retained as the selector/social thumbnail source.
- `fish-sprites-source.png`: transparent six-fish sprite sheet used for the real-time movement layer.

The generated assets contain no third-party logos, text, or externally sourced media. Optimized runtime derivatives live in `public/scenes/sukoon/`.
